# Mp. Jeremiah Umaru Campaign Website

A responsive campaign website and browser-based supporter poster studio built with semantic HTML, modern CSS, native ES modules and Vite.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

## Redesign highlights

- Complete visual refresh using the SDP orange, green and white identity
- Deep forest-green campaign hero with prominent candidate photography
- Updated typography, spacing, buttons, navigation and section hierarchy
- Redesigned delivery-record section with responsive two-column statistics
- Cleaner biography and credentials layout
- Rebuilt supporter poster studio styling while preserving its existing functionality
- Improved mobile layouts for navigation, record cards, profile details and poster preview
- Accessible focus states, reduced-motion support and existing SEO/social metadata

## Existing functionality retained

- Mobile navigation
- Two poster templates: Classic and Modern
- Client-side photo processing; supporter photos are not uploaded
- Live poster preview
- PNG download and Web Share support where available
